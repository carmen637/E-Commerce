**Sistema de gestión E-Commerce**

Aplicación de escritorio desarrollada con la clase Swing de Java con arquitectura Modelo-Vista-Controlador que permite gestionar un sistema de comercio electrónico. Se conecta a una base de datos MYSQL mediante un conector JDBC con interfaz gráfica para administrar productos, clientes y pedidos.

**Características:**
 - Gestión de clientes: alta, baja, modificación y consulta.  
- Gestión de productos: control de stock, precios, descripción y CRUD completo.  
- Gestión de pedidos: creación, modificación, asignación de cliente y productos.
- Gestion de carrito: Agregar productos al carrito o eliminarlos.
- Conexión con base de datos MySQL mediante el conector JDBC.  
- Interfaz gráfica (Swing) con ventanas separadas para cada módulo (Clientes, Productos, Pedidos).  
- Arquitectura MVC que separa la lógica de negocio, interfaz y acceso a datos.

  **Tecnologías utilizadas**
  -Java
  -Base de datos
  -Conector JDBC
  -Patron de diseño: MVC
